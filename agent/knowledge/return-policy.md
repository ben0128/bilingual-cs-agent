# Nova Mart 退貨政策 / Return Policy

## 退貨期限 / Return window
- 到貨後 7 天內可申請退貨。
- Returns can be requested within 7 days of delivery.

## 退貨條件 / Conditions
- 商品未使用、包裝與配件完整，並附上發票。
- Items must be unused, with original packaging, accessories and invoice.

## 不可退貨品項 / Non-returnable items
- 客製化商品、生鮮食品、已拆封的個人衛生用品、數位序號。
- Custom-made items, fresh food, opened personal hygiene products, digital codes.

## 退貨流程 / How to return
1. 在訂單頁或透過客服申請退貨。 / Request a return on the order page or through support.
2. 物流 1-3 個工作天內到府收件。 / A courier picks it up within 1-3 business days.
3. 收到商品後 3-5 個工作天完成驗貨。 / Inspection takes 3-5 business days after we receive it.
4. 驗貨通過後 7-14 個工作天退款至原付款方式。 / Refunds go to the original payment method within 7-14 business days after inspection.

## 運費 / Shipping fees
- 商品瑕疵或寄錯：運費由 Nova Mart 負擔。 / Defective or wrong items: Nova Mart pays return shipping.
- 其他原因：每筆訂單可免運退貨一次。 / Other reasons: one free return per order.

## 換貨 / Exchanges
- 同款商品可換尺寸或顏色一次。 / One size or colour exchange per item.
